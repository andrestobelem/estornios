# Convenciones del repositorio

- Usar Conventional Commits con scope obligatorio: `tipo(scope): descripción`.
- Crear commits atómicos: cada commit debe cubrir un único cambio lógico y ser verificable por sí mismo.
- Incluir las pruebas correspondientes junto con el cambio que verifican.
- Separar cambios independientes y evitar mezclar refactorizaciones ajenas a la tarea.
